# Leodis report design v2

Review prototype using the existing DocReport contract and React PDF renderer. Production files in packages/documents are unchanged.

Run render-examples.mjs from the repository root with Node to regenerate the two PDFs under output/pdf. The source is in src; JavaScript alongside this README is generated by the example builder. Fonts are loaded from packages/documents/fonts. Evidence images and sample report data are under rendered.

The design retains the existing charcoal, brass, Archivo and Plex Mono identity, branding positions, title metadata, action summary, numbered updates, optional evidence and final sign-off. Examples use fictional findings and image placeholders and are marked accordingly. The actual logo and accreditation artwork are still placeholders supplied by the existing branding configuration.

Updates use a flowing lead section and separately flowing evidence. Small lead sections stay together; long text may split. Photos and captions stay together and retain their update reference. Sign-off stays together after the final update. Summary references follow observation numbers, including when progress-only entries are omitted from the summary.

Verified: one-page two-update example; three-page five-update example with one full-width image and two paired images; rendered-page inspection; preservation of all example text and actions; page numbering; TypeScript check.

This is a review prototype, not a production rollout. Before integration, exercise very large action registers, unusually long headings, signature images, and long individual update sections. The inherited Plex Mono font has a fontkit parsing issue for space glyphs; sample reference codes contain no spaces. Do not broaden the use of that font without resolving the font issue.
